# From-scratch notebooks

Every notebook below has a **from-scratch twin**: the same model or algorithm rebuilt in
pure Python / PyTorch, one step at a time, with a picture, a Mermaid diagram and an
animation for each step. The twins are generated from Markdown sources in
`notebooks/_from_scratch_kit/sources/` (see the kit's README).
