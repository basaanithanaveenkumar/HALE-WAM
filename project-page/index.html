Abstract

Robot policies that can also predict the visual consequences of their actions are easier to inspect and can learn from video without action labels. HALE-WAM is a 176M-parameter world–action model that, from a few camera frames, a proprioceptive state and a language instruction, jointly generates a text response, samples a continuous action chunk with a conditional flow-matching head, and imagines future RGB frames with a Diffusion Transformer.

All three outputs are read from a single causal mixture-of-experts transformer through special tokens. Each predicted frame receives its own conditioning vector, built from a cross-attended query, a sinusoidal frame-index embedding, a pixel encoding of the last observed frame and a learned null token for classifier-free guidance, which modulates the DiT through a gated adaLN-Zero pathway. Frames are sampled with Heun's second-order solver, and training adds VGG-perceptual, SSIM and temporal-smoothness losses on the analytic clean-frame estimate to reduce blur.

Highlights

Perceive · Reason · Act · Imagine

One MoE decoder (8 layers, 6 routed + 2 shared experts) read by three heads: language, action and world model.

Flow-matching actions

A velocity MLP conditioned on the <halo_action> hidden state maps noise to a 16-step chunk in 24 Euler steps and can represent multi-modal actions.

Per-frame DiT conditioning

Decoder query + cross-attention, sinusoidal frame index and pixel anchor, fused with the timestep through a sigmoid gate into adaLN-Zero.

CFG + Heun sampling

A learned null context (p = 0.1) enables classifier-free guidance, and a second-order Heun solver halves truncation error versus Euler.

Anti-blur losses

VGG perceptual, SSIM and temporal smoothness on x̂₁ = x_t + (1−t)·v, which comes for free from the straight-line flow.

Practical training

AMP, gradient accumulation and checkpointing, full-state resume, TensorBoard, and GIFs of text, actions and imagined frames.

Quick start

git clone https://github.com/basaanithanaveenkumar/HALE-WAM && cd HALE-WAM
uv venv && source .venv/bin/activate && uv pip install -e .
python scripts/train.py --dataset moma --moma_data_root /path/to/moma \
  --moma_num_frames 5 --num_predict_frames 5 --batch_size 1 --grad_accum_steps 8
logits, action_h, vis_ctx, wv_h = model(images, input_ids, attention_mask, states)
actions = model.sample_actions(action_h)              # [B, n_act, 16, action_dim]
frames  = model.predict_visual_future(images, vis_ctx, num_frames=5,
                                      world_video_query_hiddens=wv_h)["rgb"]
